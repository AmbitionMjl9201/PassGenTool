# 随机密码生成器

一个基于 Python 和 CustomTkinter 的图形化随机密码生成工具，支持自定义长度与字符类型，提供理论熵值与基于 `zxcvbn` 的实际强度估算，并具备历史记录管理及纯文本导出/导入功能。

## 功能特点

- **灵活的密码参数设置**  
  可独立选择大写字母、小写字母、数字和特殊符号，支持通过滑块或输入框精确设定密码长度（4 ~ 128 位）。

- **双重强度评估**  
  - **理论熵**：基于所选字符集大小计算的信息论上限，用于衡量密码的随机性。对所有长度均有效。  
  - **实际强度估算**：集成 `zxcvbn` 库，模拟现实攻击场景下的破解难度，给出更贴近 KeePass 等专业工具的评估值。  
  - 评估结果均以“约 xx 比特”的形式展示，并标注强度等级（弱、一般、强、非常强）。  
  - **注意**：`zxcvbn` 对输入密码长度存在内部限制，当密码超过约 70 位时可能无法完成估算，此时界面将显示“无法估算”，若需获得实际强度参考，建议将密码长度控制在 70 位以内。

- **历史记录管理**  
  自动记录每次生成的密码、时间戳及熵值，支持：
  - 列表查看与滚动浏览
  - 选中并复制历史密码
  - 单条删除或一键清空全部历史
  - 程序关闭时自动保存，启动时自动恢复

- **纯文本导入/导出**  
  支持将历史记录导出为 `.txt` 文件（也可选 `.json`），导出内容便于阅读和备份。<br>
  导入功能可从之前导出的 `.txt` 或 `.json` 文件中恢复记录，方便跨设备迁移。

- **现代化图形界面**  
  基于 CustomTkinter 构建，界面清晰，支持系统主题（明/暗）自适应，无需命令行操作。

## 技术栈

- Python 3.8+
- [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) 用于构建 GUI
- [zxcvbn](https://github.com/dwolfhub/zxcvbn-python)（可选）提供实际强度估算

## 安装与运行

### 1. 下载可执行文件（推荐）
前往 [Releases](https://github.com/AmbitionMjl9201/PassGenTool/releases/tag/v1.0.0) 页面下载最新的 `PassGenTool.exe`，双击即可运行，无需安装 Python 或任何依赖。

### 2. 自行打包为 exe
```bash
pip install pyinstaller customtkinter
pip install zxcvbn
pyinstaller --onefile --windowed PassGenTool.py
```

## 使用说明

1. 在界面顶部选择所需字符类型，并通过滑块或直接输入设置密码长度。
2. 点击“生成密码”按钮，生成的密码将显示在结果框中，并自动添加到历史记录。同时会显示理论熵和实际强度（若已安装 `zxcvbn` 且密码长度未超过约 70 位）
3. 可通过“复制”按钮快速将当前密码复制到剪贴板；在历史记录列表中选中条目后，也可使用“复制选中”按钮复制历史密码。
4. 历史记录列表展示每次生成的密码、时间及熵值；点击某一行可将其选中，随后可复制或删除该条记录；“清空历史”将删除全部记录，操作前会弹出确认对话框。
5. 点击“导出”可将所有历史记录保存为 `.txt` 文件（默认），或选择 `.json` 格式；点击“导入”可从之前导出的 `.txt` 或 `.json` 文件恢复历史记录，导入时会自动合并到现有列表中。

## 熵值与强度说明

- 理论熵：计算公式为 `L × log₂(N)`，其中 `L` 为密码长度，`N` 为所选字符集的大小。该值表示在已知字符集情况下的最大可能猜测次数，反映了密码的随机性。无论密码多长，该值均可正常计算。
- 实际强度（zxcvbn）：通过分析密码中的模式、键盘序列、常用组合等，估算攻击者实际需要的猜测次数，并转换为比特值。该值通常低于理论熵，但更贴近现实攻击成本。
- 所有熵值均标记为“约”，以表明其为估算值，仅供参考。
